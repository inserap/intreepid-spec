# Post-mortems — spec

Rétrospectives de phase, de release ou d'incident. Les post-mortems sont un **process artifact** : ils vivent dans le spec repo (pilotage), pas dans l'impl (livrable) — cf. ADR-0003.

Déclenchement : via une slice dédiée du spec. La doctrine de post-mortem est partagée par tous les projets INSER AI (voir `<STANDARDS>/PROJECT-PROMPTS.md` pour la formulation canonique du prompt, à venir).
