# Journal — intreepid

Entrées narratives append-only documentant l'évolution du projet, session par session.

Contrat (cf. `<STANDARDS>/conventions/journal.md`) :
- **Une entrée par session productive** maximum.
- Format : `YYYY-MM-DD-<topic>.md`, narratif, avec sections Context / What was decided-shipped / Open questions evolved / Lessons learned / Pointers.
- **Append-only.** Les entrées existantes ne sont jamais modifiées sauf correction de typo.

Template : [`TEMPLATE.md`](TEMPLATE.md).
